# TodoApp

This is your renamed TodoApp learning project. It is built with React, Vite, and Tailwind CSS as a hands-on productivity dashboard.

## Current app features

- Add task with title and status (`pending` / `done`)
- Card-based task list UI
- Delete tasks
- Toggle task completion
- Filters: `all`, `pending`, `completed`
- Stats panel: total tasks, completed, pending
- Responsive layout with sidebar and header

## Learning focus

This is not just a scaffold. The project should require human input and intentional decision-making, so your app reflects your learning progress.

### Human-centered flows to add next

1. Completion requires reflection
   - require a short note before marking a task as done
2. Draft / commit task workflow
   - add tasks as drafts, then commit them when ready
3. Daily planning and focus selection
   - choose one task to focus on today
4. Human review stats
   - record effort, confidence, or follow-up notes
